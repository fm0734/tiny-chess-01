# tiny-chess-01: a 4 KB Python chess engine

[![tiny-chess-01](https://make.fun/badge/tiny-chess-01.svg)](https://make.fun)
[![rank](https://make.fun/badge/tiny-chess-01/fm0734/tiny-chess-01/rank.svg)](https://make.fun)
[![reward](https://make.fun/badge/tiny-chess-01/fm0734/tiny-chess-01/reward.svg)](https://make.fun)

An original 0x88 engine in one packed `main.py` (at most 4,096 bytes):
negamax alpha-beta with quiescence, a transposition table, killer moves
and a fixed node budget, so replays play the same moves. Python 3.13,
standard library only. Built for the tiny-chess-01 competition on
[make.fun](https://make.fun).
